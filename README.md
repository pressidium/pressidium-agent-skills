# Pressidium Agent Skills

Connect to the hosted Pressidium Dashboard MCP server, then ask the agent to install/update Pressidium skills.

Download [skills-latest.zip](https://github.com/pressidium/pressidium-agent-skills/releases/latest/download/skills-latest.zip).

Read [INSTALL.md](./INSTALL.md) for Cursor, Claude Code, Codex and Claude Desktop instructions, including section 3 (`pressidium_skills`). The pack contains `pressidium/VERSION`, `pressidium/blocks/` and `pressidium/composites/`.

Cloning this repository is a human option. Guided agents use the Release ZIP.
